# 欢迎视频接入

用户确认《视频_ad0-0201_修订版.mp4》并授权继续接入网站。复用既有简约风格、语言/主题开关与个人内容。

1. 保存经确认的原始无声视频，导出网页 H.264 副本、首尾封面。
2. 使用同一个视频元素保持构图连续：自动开场；3.65–4.75秒静息循环；滚动或点击触发4.75秒后的真实手势；结束保持尾帧并显示 MY WORLD / EXPLORE。
3. 提前滚动记为待播放，不打断开场。减少动态、播放失败、媒体加载失败提供静态封面与直接进入。保留原生页面滚动与键盘通路。
4. 点击 EXPLORE 过渡至 about；顶部品牌可返回并重播。手机完整显示头顶和手指，中英文控制可用。
5. 先运行交互失败测试，再实现；检查真实播放时间、结尾、提前输入、回退、手机、主题语言，运行类型检查及生产构建。

限制：当前批准的视频只有暖白背景版本，暗主题仍使用此版本，不伪造衣服换色。独立深色视频需后续另行制作。静息循环取自现有成片，是否无缝以预览为准。
