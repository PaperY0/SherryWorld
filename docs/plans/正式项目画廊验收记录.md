# 正式项目画廊验收记录

日期：2026-10-04。工程：`site/`。本轮交付为正式画廊迁移与项目资料接入；人物仍使用 V5 静态视觉稿。

## 已交付

- 保留 `BUILT IN MY OWN WAY.` 全大写单行标题，不恢复已删除的两行中文说明。
- 桌面约 4–5 张大卡片，边缘加宽加高，上边缘向上、下边缘向下；手机主卡片与两侧预览。
- 从上方错峰入场，默认右向左循环。鼠标左右位移改变方向，停止移动约 1.1 秒恢复默认方向；速度缓动。
- 拖动参观、暂停与前后切换；拖动超过阈值不打开详情。纵向滚动保留浏览器行为。
- 点击卡片打开项目介绍、参与方式、当前记录状态和 GitHub 链接。弹窗打开时暂停，关闭后恢复此前的播放选择。
- 原生弹窗支持 Esc 和焦点归还；方向键参观时焦点跟随可见卡片。减少动态偏好默认暂停，跳过入场动画。
- 画廊、目录和详情支持中英文与双主题；切换设置不重建动画控制器。
- 作品 13 个、学习 Fork 4 个，完整目录 17 个；Fork 保留真实上游地址。

## 数据来源与维护

本轮读取 PaperY0 公开仓库元数据，新增 SherryWorld，保存为 `../../data/GitHub项目公开快照-2026-10-04.json`。原始快照保持不变。此前 9 个项目的 README 摘要证据保留；本轮未重新运行其他项目，也未验证其性能。用户自述的全栈负责与 AI 辅助开发作为参与文案，不推断为独立原创代码证明。

工程通过 `npm run sync:projects` 将维护源同步为 `src/content/project-snapshot.json`；构建不依赖工程目录外的 JSON。类型化项目内容及展示顺序在 `src/content/projects.ts`。
