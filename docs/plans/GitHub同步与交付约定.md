# GitHub 同步与交付约定

仓库：https://github.com/PaperY0/SherryWorld

用户已授权：在当前目录搭建，每完成一步提交并同步到此仓库。

## 交付节奏

1. 完成一个有独立验收结果的步骤。
2. 执行该步骤必要的检查，记录实际通过情况与未完成项。
3. 检查差异及提交文件，避免混入密钥、依赖、缓存和本地备份。
4. 使用能说明成果的提交信息，创建普通 Git 提交。
5. 推送至当前工作分支，核对远端提交号。
6. 向用户说明此次交付、验证结果与提交链接。

每一步指一个可验收交付，例如双主题工程骨架、内容栏目、正式画廊、人物小样接入，而不是每修改一行就提交。过程中不强制推送、不改写已推送历史。遇到远端新提交先检查并正常合并，避免覆盖其他修改。

## 初始同步范围

- 提交：设计文档和 PNG、报告、计划、交互原型、公开项目快照、目录说明。
- 本地保留：`work/` 内临时资料与整理前备份。
- 排除：依赖、构建产物、日志、环境密钥。
- 用户原始照片尚未复制到本工程，也不会因初始化而自动上传外部聊天目录的照片。

正式工程仍按 `2026-10-03-first-build.md` 执行。初始资料提交不代表网站已构建、运行、发布或真实 3D 人物已制作。
