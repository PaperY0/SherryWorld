> 执行方式：在当前会话按任务顺序推进，使用 executing-plans 工作流；每项完成后记录实际结果。所有工作位于 `C:/Users/wsy19/Desktop/Personal World`，不另建工作目录。

**目标：**交付可运行的双主题网站骨架、保留已确认效果的正式项目画廊，以及用于验收相似度和表情的真实 3D 人物小样。

**架构：**正式工程放在 `site/`。网页内容与 3D 场景分离，项目数据使用本地快照，人物资产通过独立清单加载。画廊优先迁移现有 CSS 3D 方案，不重做已经认可的视觉方向。

**技术栈：**Next.js、React、TypeScript、CSS；人物场景使用 Three.js / React Three Fiber。执行工程任务时核对官方版本要求并锁定实际依赖。第一轮不需要账号系统、数据库或管理后台。

## 全局约束

- LIGHT：暖白底、近黑字、柔粉点缀；DARK：暖炭灰底、白字、柔粉点缀。拒绝金属质感与整站纯黑。
- 第一屏只保留 PERSONAL SPACE、LIGHT / DARK、居中上半身人物，完整头顶必须在画面内。
- 人物略拽、从容，保留黑发、刘海、大黑框眼镜等识别点；Light 黑针织、Dark 珍珠灰针织。
- 画廊标题固定为 BUILT IN MY OWN WAY.，全大写单行；不恢复两行已删除的中文。
- 桌面画廊主要可见 4–5 张，边缘加宽加高，上沿向上、下沿向下。
- 默认右向左；鼠标向左移动则左流，向右移动则右流；拖动不误触详情；纵向滚动优先。
- 项目数据区分 12 个非 Fork 与 4 个 Fork，保留来源和证据状态；不虚构项目效果、贡献和成绩。
- 用户自述全栈负责、AI 辅助开发。求职方向 AI / 后端 / Agent。
- 手机可阅读可操作，尊重减少动态设置；没有实际 GLB 时不把图片倾斜称作真实人物 3D。
