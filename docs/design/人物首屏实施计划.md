# Sherry 人物首屏实施计划

用户已授权先实现首屏，后续栏目只拆解、少量逐步修改。本轮执行既有《参考站拆解与Sherry改版方案》的第一、二步。

## 范围

- 新增 `/stage` 对照预览，保留 `/` 当前欢迎视频和全部内容。
- 构图遵循参考站：居中大人物、背后超大循环文字、两侧小字、底部关键词。
- 替换为已认可的 Sherry 形象、黑粉双主题、本人原始签名逐笔揭示。
- 双语、减少动态、移动端与失败回退必须可用。
- 不承诺已掌握所有 GPU 细节；技术报告分清源码理解、实际实现与尚未验证。

## 文件与步骤

1. `site/tests/stage.spec.ts`：先写预览可访问、语言主题、书写完成/重播、手机和减少动态检查；运行确认未实现时失败。
2. `site/src/components/stage/StageHero.tsx`、`stage.css`：独立舞台。原型用 CSS/RAF 表达首屏必要的时间线与循环，后续长页若移植再引入 GSAP/ScrollTrigger，不为一屏重复引入整个参考栈。
3. `Signature.tsx`：原 PNG 叠 SVG 分笔遮罩。保留最终图，不以旧描绘字形替代。轮廓和笔顺需要真实截图检查。
4. `site/src/app/stage/page.tsx`：独立入口。页内提供原站入口，不接管其他栏目。
5. 制作透明人物 PNG，保留源文件；从生成目录复制到当前项目。
6. 运行类型/构建及 Playwright；观察桌面双主题、手机与书写中间帧，修复后提交本轮文件。
7. 新增《参考站逐区设计细节与核心技术》：区域位置、层级、触发、运动、文案、最小修改项；链接完整原文表。

## 验收

- 1440×900 与 390×844 无横向溢出，人物头顶完整。
- 签名自动书写一次，可重播；减少动态时直接完整显示。
- LIGHT/DARK、中英即时切换；没有自动声音。
- 动画监听及 RAF 卸载清理；标签页隐藏暂停持续循环。
- 原首页欢迎视频与 EXPLORE 门槛回归通过。
