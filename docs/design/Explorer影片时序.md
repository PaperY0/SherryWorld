# Explorer 镜头同步

影片：`fall-awakening-v4.mp4`。镜头和文字以视频的 `currentTime` 为准，滚轮不再推进影片内的放大或压暗动画。

| 影片时间 | 画面 |
| --- | --- |
| 0–5.05 秒 | 人物转身，保持居中的小方形画幅 |
| 5.05–5.55 秒 | 开始失足时迅速铺满视口 |
| 8–10.9 秒 | 随下落逐渐压暗 |
| 9.15–10.5 秒 | 图一 “The abyss… ascension.” 渐显并停留 |
| 12.3 秒起 | 人物重新亮起，恢复影片亮度，图一淡出；启动2.6秒自动滚动与画面交叠过渡 |
| 过渡末尾 | 连续背景先就位，再亮出图二 “Through the storm…” |

观看片段时向下滚动不会提前跳过镜头；向上滚动、Esc、导航键可中止。离开后重新进入可从头播放。隐藏标签页暂停影片和自动镜头；减少动态效果偏好下展示静态可读内容。

实现：`site/src/components/stage/explorer-film-motion.ts`。后续换片时需重新测量节点。
