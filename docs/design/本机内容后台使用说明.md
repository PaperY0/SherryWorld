# Sherry 本机内容工作室

后台：http://127.0.0.1:3200/admin

前台：http://127.0.0.1:3200/stage?v=pink-fire

## 日常使用

1. 进入“项目”“技能与照片”或“城市与生活”，选择现有内容或新增。
2. 项目支持封面、简介、详情、标签和链接；技能支持介绍和照片；城市支持书本、短句、颜色和照片。
3. 照片可多选上传，支持 JPG、PNG、WebP、GIF，单张最多15MB。生活照片分为个人照、风景和美食。
4. 上移、下移调整显示顺序。移除只改变清单，原图继续保留。
5. 点击“保存全部修改”，刷新前台即可生效，无需重新构建。不同板块的修改会一起保存。

英文标识使用唯一的小写英文、数字或短横线。空照片集合显示预览占位；空项目、城市集合显示空状态。关闭未保存的页面会提醒。

## 保存与备份

默认保存在 `site/data/studio/`：

- `content.json`：项目、技能、城市及照片清单。
- `media/`：上传的图片原文件。
- `backups/`：每次保存之前的上一版内容。

此目录不进入 Git。迁移、备份时请复制整个文件夹。“导出备份”仅导出 JSON 清单，不包含图片文件。

恢复上一版：关闭后台编辑窗口，将选中的 backups JSON 复制为 content.json，然后重新打开后台、刷新前台。原图仍保留，旧清单可以继续使用。

首次使用自动读取现有的4个项目、4个技能和5座城市。源码默认内容与 public/images 内的原素材不被覆盖。

## 本机服务

继续使用当前网站服务，独立后台路径为 `/admin`。服务绑定127.0.0.1，本版没有公网账号体系，不应直接通过反向代理向公网开放。

写入接口检查本机 Host、同源 Origin 和专用请求头；版本冲突会阻止覆盖另一窗口刚保存的内容。上传只接收受支持的位图格式，文件路径由服务端生成。

可用 SHERRY_CONTENT_DIR 环境变量指定其他本地保存位置。自动化后台测试使用独立测试目录和3201端口，不修改日常内容。
