## 2. 签名替换：可以实现逐笔连写

参考站人物是独立 AVIF 图片，脸前红色装饰来自单独 Three.js 模型场景，而不是画进肖像里的贴图。替换人物和替换装饰可分别处理。

推荐方案：保留选定的透明 PNG 作为最终外观，在 SVG 中手工描出每一段笔画的中心路线，用依次推进的遮罩揭示原图。这样保留笔形、粗细、粉色与纹理，不用电脑字体代替。PNG 不包含真实笔顺，笔顺需要手动安排；交叉点需要分段遮罩，防止下一笔提前露出。

建议时序：

1. 人物和背景先建立，脸部保持可见。
2. 在参考站装饰落到面部的时机，签名进入人物前景；建议位置在面部下缘至肩胸区域，避免长期盖住眼睛。
3. 按 S → h → e → r → r → y 的视觉笔顺连续写出，建议 2.2–3 秒，保留自然连笔与必要的提笔。
4. 完成后停留约 0.6 秒，再缓慢缩小移至角落，成为长期品牌标识。
5. 减少动态模式直接显示完成签名；动画不应阻塞导航和浏览。

三种实现选择：

|选择|效果|取舍|
|---|---|---|
|A 原图＋逐笔遮罩（推荐）|最接近选定签名，真正按笔顺出现|需要手工调路径、交叉处及节奏|
|B 重绘成完整 SVG|易缩放、易控制路径动画|与原图笔触会有区别，需要再次确认外观|
|C 原翼形换粉色|保留现有模型运动，快速对照|仍是别人的装饰，不是你的手写签名|

A 在技术上可行，无需先退回 C。当前尚未制作逐笔动画小样，不把可行性当成已验收效果。移动端使用独立尺寸和安全区域，签名不要被裁切。

## 4. 入口流程需要统一

现网站：欢迎视频 → 滚轮只继续手势 → MY WORLD + EXPLORE → 点击后进入内容。这是现有实现。

参考站：加载入场 → 人物主视觉 → 可以直接滚动浏览。这是另一个入口结构。

推荐先保留你确认过的 EXPLORE 门槛，将参考站的舞台、签名和大字做成欢迎页小样，进入后的叙事长页再逐区改。若改为直接滚动整站，应明确取消旧门槛，不同时要求“滚轮固定欢迎页”和“滚轮立即进入下一栏目”。目前两种方案没有合并实施。

## 5. 动手顺序与每步验收

1. **首屏独立小样**：在当前项目新增隔离的设计预览入口；旧首页保持可用。只完成黑粉背景、本人角色、超大字布局、导航，不移植整站。检查桌面/手机头顶留白与边缘融合。
2. **签名动画小样**：原图逐笔揭示，先解决 e、双 r、y 收笔和交叉处穿帮；展示一次完整书写及静止结果。效果确认后再接落下/位移节奏。
3. **入口编排**：统一视频、签名、标题和 EXPLORE 的先后，确认是否保留现视频门槛。
4. **关于与能力**：替换身份和真实内容；补中英；不继承他人数字。
5. **项目画廊及详情**：先确认横向弧形还是纵向逐项，再接现有项目数据、链接、截图与贡献。
6. **兴趣、生活、旅行**：按真实主题搭照片留白；不编造故事。
7. **结尾与全站打磨**：联系、主题、语言、手机触控、键盘、减少动态、错误回退、性能。

每一步只提交本次文件，检查后再同步仓库。先评审第一屏的实际视觉，不一次性推倒所有已确认内容。现阶段不需要重做人物 3D 模型。
