# 双语与全站设置

本轮授权：开始正式网站骨架，加入中英文切换，完成一步提交一步。

## 实现选择

使用一套页面和类型化中英词典。初始正文中文；首次主题跟随系统偏好。右上角提供中文 / EN 与 LIGHT / DARK，选择写入本地存储，刷新恢复。存储被禁用时本次浏览仍可切换。

中文和英文只改变文案，不重载路由，不重置主题或浏览位置。HTML lang、页面标题、人物替代文本、控件标签和栏目正文一起切换。PERSONAL SPACE、A WORLD OF MY OWN、BUILT IN MY OWN WAY. 作为已确认的品牌与标题，在两种语言下保持原文与大写；EXPLORE 保留英文。

暂不做语言专属 URL、翻译接口和在线自动翻译；正式分享页面的双语 metadata 在求职与分享阶段完善。GitHub 项目名称和代码术语不翻译。

## 首轮范围

- 双主题与双语言全站设置、持久化、无障碍状态。
- 人物序幕的静态视觉参考及后续模型接入位置。
- 欢迎入口与关于我、项目、兴趣、生活、旅行、联系区的轻量骨架。
- 正式画廊、真实模型、视差镜头为后续任务，当前不标已完成。

## 验收

两种语言与两种主题的四种组合可用；刷新保持设置；首次跟随系统主题；错误存储和禁用存储不使页面崩溃；切换不跳回顶部；手机无横向溢出；中英文辅助标签一致；项目和联系入口地址真实。
