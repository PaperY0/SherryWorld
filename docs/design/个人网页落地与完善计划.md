# PaperY · 个人网页落地与完善计划

日期：2026-10-03。这是完整交付路线与验收任务清单，作为后续各阶段实施的依据；本轮不创建正式网站工程。

> 执行方式：后续使用 executing-plans 按阶段推进。每阶段形成可查看成果，完成验收再进入依赖它的工作。本计划没有安排额外子代理或自动发布。

**目标：**将已确认的黑粉双主题、居中人物入口、滚动叙事、环形项目画廊和个人内容，落地为可访问、可维护、对求职有帮助的个人网站。

**架构：**正文与详情页使用普通网页结构，项目、照片和文章由结构化内容驱动。3D 人物作为独立场景加载；滚动动画、鼠标响应和主题共享明确状态。项目画廊沿用已经认可的 CSS 3D 方案，完整站点再组件化和优化。

**拟用技术：**Next.js、TypeScript、React、Three.js / React Three Fiber、GSAP ScrollTrigger、CSS 主题变量、结构化数据与 Markdown 内容。具体稳定版本及兼容性在工程阶段核验后锁定。

- [ ] 准备可审阅预览链接，再选择正式域名与上线配置；公网发布作为独立步骤执行。
- [ ] 对上线版本复验主题、项目链接、图片、模型、直达案例和手机体验。
- [ ] 保存发布版本、检查记录和内容维护说明 `docs/content-maintenance.md`。
- [ ] 新项目从内容索引加入；照片、旅行和故事从各自内容目录更新，不改底层动画。
- [ ] 保留 GitHub 有效快照；同步失败时继续显示旧数据，记录快照日期。
- [ ] 内容变化后检查相关页面和分享图；持续保留项目真实状态与 Fork 来源。

**验收：**正式地址实际可访问且核心路径复验通过；内容可以持续更新，而不是只得到一张静态截图或一次性动画演示。

## 16 · 下一步的具体顺序

1. 以本计划固定需求，将已确认画廊与双主题作为对照。

无需重新确认你已经明确的版式和功能。后续只在缺少真实素材、模型制作资源或具体上线信息时，围绕那个缺口提出问题；每次验收都有能查看的结果。
