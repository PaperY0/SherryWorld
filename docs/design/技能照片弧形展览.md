# 技能照片展览

2026-10-18。用户确认采用旧首页的弧形展墙（拖拽、左右切换、点击放大），不是 stage 的竖向项目滚动。

## 当前功能
长卷四项技能各有 EXPLORE 入口。打开原生全屏 dialog，以当前黑粉曙光背景、花体标题呈现独立照片集合；复用旧展墙 mountGallery 控制器，保留弧形透视、鼠标方向跟随、拖拽、自动移动、左右切换及暂停。点击照片进入同一展览内的大图层，支持左右键、上一张/下一张、Escape 先退大图再退出展览。关闭后恢复焦点、页面滚动与 overflow。减少动态模式默认暂停自动移动。

当前四项：AI Exploration / Motion & Interfaces / Systems & Intelligence / Connected Creation。沿用长卷文案，未增加技能数量、熟练度或成果指标。

## 照片内容边界
用户确认了展墙形式，尚未回复照片先如何处理。按后补处理，正式 photos.json 都为空数组，不把装饰图或测试图伪装成技能成果。无照片时显示 A collection in progress.。四个技能都能打开。

## 后续接入
把实际照片放到对应目录，然后编辑该目录 photos.json：
- site/public/images/skills/ai-exploration/
- site/public/images/skills/motion-interfaces/
- site/public/images/skills/systems-intelligence/
- site/public/images/skills/connected-creation/

示例（不是当前正式内容）：
```json
[
  {
    "src": "/images/skills/ai-exploration/example.jpg",
    "alt": "Accurate description of the photograph",
    "caption": "Short optional caption"
  }
]
```

每次打开技能时加载自己的 JSON；src 只接受本地 /images/ 图片路径，alt 必填。无需硬编码照片数量。单张或少量图片仍可浏览，但展墙会重复布局卡片以保持连续弧形，不把重复卡片计作新照片。

## 验证
生产构建通过。技能展览三项检查及现有长卷三项共六项通过：四组独立空集合；测试照片下的拖拽、切换、暂停、放大、左右键与两级 Escape；焦点和原滚动恢复；手机及减少动态模式；长卷回滚与连续背景。

照片交互测试通过 Playwright route.fulfill 临时提供三张现有素材。它们仅是测试夹具，不写入正式照片列表。人工核对测试展墙截图，黑粉背景、花体与图片空间关系符合当前 stage。旧首页项目展墙未修改。
