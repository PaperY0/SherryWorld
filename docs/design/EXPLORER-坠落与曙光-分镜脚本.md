# EXPLORER｜坠落与曙光：视频分镜及网页衔接

## 核心叙事
低谷、失败与挫折是人生的常态，也是成长的一部分。不是坠落后突然无所不能，而是保留好奇、理解经历，再把学到的东西变成创造能力。先抑后扬：背影的未知 → 回身面对 → 猝然失衡 → 深坠与沉静 → 一线暖光 → 能力展开。

视频规格建议：一段 15 秒、16:9、1920×1080 或以上、24/30fps、连续长镜头、不循环、无字幕/水印。网页控制播放进度，不自动循环。主体放在画面横向中央 35%–65% 区域，手机另做竖版会更好；横版直接裁切不能保证保持同样构图。

角色：使用 Sherry 的人物参考，锁定脸、眼镜、深棕发与浅色挑染、服装。当前首页主要是半身形象；生成全身前先补同服装的正面/背面全身参考，避免模型自行改鞋、改裤装或改变体型。不把参考站的男性剪影当作 Sherry。

## 可复制的生成提示词
以提供的 Sherry 正面和背面全身角色参考为唯一人物，严格保持脸型、黑框眼镜、深棕长发与浅色挑染、同一服装、体型和鞋。生成一段 15 秒的电影感连续长镜头，第三人称，16:9 横屏。黑色、暗玫粉、黑紫为主，结尾有极克制的暖白粉曙光。场景是无具象地标的抽象深渊边缘，空间有柔雾与少量细颗粒。人物全身完整，手脚解剖自然，始终在横向中央区域。

0–2 秒人物背对镜头安静站立，发尾轻轻浮动，摄影机轻微前移；紧接着 2–4.8 秒人物自己先转头再转肩，再转动全身面对镜头，面容清晰并短暂停留，镜头不绕人替代转身。在同一次连续运动中，4.8–6.2 秒人物肩胸突然短促后挫，表现像被无形外力推了一下，先失衡，再脚跟离地、双手自然张开，一条腿试图寻找支撑；没有其他人，没有施力的手。紧接着 6.2–9.2 秒人物从边缘向后下方坠落，先脚失去支撑再身体倾斜，头发与衣摆自然向上飘，镜头向前探出略微俯拍，保持平稳，人物逐渐远离。9.2–12 秒持续向深处坠落，环境暗粉渐渐退成黑紫，人物从中远景缩为较小但完整可辨认的剪影，轮廓保留一线柔粉光，颗粒轻轻向上经过，姿态渐渐平静。12–13.5 秒接近最暗，仍保留微弱人体轮廓和空间层次，不要纯黑，不落地。最后 13.5–15 秒下方深处出现极细的暖白偏粉曙光，慢慢勾亮脚尖和衣摆，人物微微抬头、舒展手指，镜头轻微向光倾斜，结束在安静但仍有希望的远景。人物不飞升，曙光不过曝。

单一镜头，无剪切、无黑场转场、无跳帧、无突然换景、无镜头高速旋转、无第二人物、无推人的手、无主动跳崖动作、无撞击或血腥、无翅膀、无变身、无五官漂移、无多余肢体、无文字字幕水印、无强烈镜头变焦、无配乐。声音可仅有轻微风声，网页默认静音。

## 如一次生成不能稳定完成
保留上面的一镜到底为最终目标。若生成平台有时长/一致性限制，可分为“背影→回身→失衡”（0–6.2）和“失衡→深坠→曙光”（6.2–15），用第一段最后一帧作为第二段首帧，再输出一个连续 MP4。衔接时对齐肩部角度、脚的位置、雾色、光向和镜头距离；不要用纯黑或闪白掩盖跳切。提示词不能保证一次得到正确物理动作，先检查转身和失衡这两处。
