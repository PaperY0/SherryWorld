## 页面修改
用户提供的 SVG 几何路径保持不变，以 PapillonLines.tsx 组件替换旧网格。使用 pathLength=1000 统一线段的 dasharray/dashoffset，不使用原 SVG 中的 CSS 定时 animation。GSAP 挂在现有 scrub:.75 的滚动时间线，s1→s2→s3→s4 依次为中心菱形和长针、主翼尾翼、内部切面、左右编织丝线。回滚会逆向描回。粉色 currentColor，整体透明度 .48。减少动态模式直接展示完整图案。

参考依据：本地 reference evidence/original.pretty.js 的 .svg-strokee 先计算路径长度并设置 strokeDasharray/strokeDashoffset，随后加入同一 ScrollTrigger timeline。当前实现沿用滚动控制线条进度的机制，使用用户自己的蝴蝶图案，不再保留旧网格。

## 分镜图片
使用内置 image_gen 工具生成六格连续分镜概念图，非视频，未调用 Dreamina CLI 或消耗其积分。参考角色为 site/public/images/stage/sherry-cutout-v1.png。下半身暂定深色长裤和短靴，属于本次补全的造型，不宣称是用户已提供的全身参考。

生成方向：3×2 无字六格，背影站立→回身→短促失衡→坠落→远处深暗剪影→下方细微暖粉曙光。保持黑框眼镜、深棕长发及浅色挑染、灰毛衣、深色裤鞋、第三人称电影感 3D 风格。无推人的手，无主动跳下，无撞击或血腥，无字幕水印。

首版：assets/design/explorer-storyboard/explorer-six-beats-v1.png。

首版观察：末格曙光和地貌偏壮观，超出原脚本的克制微光；挑染在不同格中不够稳定。已用同一角色和首版图作为参考，要求修订为更抽象的黑粉深渊，减少山峰与亮天空，恢复浅色挑染，末格保留深黑空间和极细的下方光线。这些分镜用于先确认构图与情绪，不能替代视频的实际动作连续性检查。
