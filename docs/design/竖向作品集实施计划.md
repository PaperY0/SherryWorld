# 竖向作品集

用户要求：先做作品集，再做 fall；顺序 Lumi / Zhiye / ShengXinGO / Realm。采用参考站竖向固定滚动舞台：当前封面放大，上下卡片缩小，右侧介绍，圆形编号及进度，背景跟随切换。封面可打开全屏详情，详情和右侧都有 GitHub 仓库链接。

## 文件
- stage-portfolio.ts：四项数据，真实仓库 URL，依据当前 README / PRD 的英文摘要、标签及素材来源。
- WorkCover.tsx：仓库现有品牌素材构成的封面，Lumi 的小图标配文字排版，其他项目使用已有插画或 logo。
- StagePortfolio.tsx / stage-portfolio.css：GSAP/ScrollTrigger 驱动卡片位置和缩放；数据单源驱动介绍和链接；固定舞台与静态回退。
- WorkDetail.tsx：原生 dialog，展开/收起动效、Escape、焦点与滚动恢复。
- StageHero.tsx：接在能力区后面，不加入 fall。

## 滚动状态
current：top25% / scale1 / opacity1；prev：top-10% / scale.3 / opacity.4；next：top60% / scale.3 / opacity.4；更远隐藏。每 100svh 展示一项，.6秒缓动追随，支持回滚。移动端封面在上、说明在下；减少动态效果时四项顺序可读，无长距离固定。
