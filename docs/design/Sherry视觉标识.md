# Sherry 视觉标识

当前网站展示名统一为 Sherry / SHERRY，包含欢迎页、人物替代文字、关于我、画廊海报标签、页脚、页面标题与元信息，浏览器图标字母更新为 S。GitHub 真实账号和仓库 URL 保留 PaperY0，避免改变外链目标和数据来源。

主标题采用静态柔粉渐变：浅粉 `#e6b5c4` → 玫瑰粉 `#c37697` → 柔粉 `#dc9db4` → 淡粉 `#edc6d2`。正文继续使用清晰的主题文字颜色。

EXPLORE 使用半透明白粉玻璃底、18px背景模糊、细白色高光边框和轻柔粉灰投影。鼠标悬停轻微抬起，键盘焦点仍保留。

签名：`site/public/images/sherry-signature.svg`，独立矢量曲线绘制、透明背景，不依赖客户端字体。最新版本按用户提供的亲笔稿重绘：保留大写S的大弧、h的直长上挑、连续的erry和y的长下行回环，去掉旧版额外下划线。淡粉渐变颜色保持原有 `#d39aac` / `#dfa9ba` / `#c98b9f`。放在欢迎页左下角，手机位置避开底部滚轮提示。原版保存为 `assets/design/signature/sherry-signature-v1.svg`。

平滑修订：将直线与曲线交接处改为连续贝塞尔过渡，柔化h/r的折返、e的连接和y的收笔。配色及10.5笔画宽度不变。上一版手写描绘保存为 `assets/design/signature/sherry-signature-handwritten-v1.svg`。
