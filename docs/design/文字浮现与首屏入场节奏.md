# 文字浮现与首屏入场节奏

参考来源：本地 Meer-Mohsin-Replica/src/app.js、scroll.js、layout.css；原站 https://www.meermohsin.me/ 。

- 背景大字从下方上移，时长 2 秒；人物延后 0.5 秒开始，3.5 秒完成上移、0.9 到 1 的缩放及亮度恢复。人物保持不透明，避免背景文字透出。
- 加载期间暂停首屏动效，加载结束后开始；减少动态效果模式直接显示完整画面。
- About 标题逐字、正文逐词随机错峰浮现：上移 40px、4px 模糊到清晰，间隔 50ms；标题单字 1.2 秒、正文单词 3 秒。艺术体 FEEL 作为一个整体保留字形。
- 三个人格标题逐字、英文描述逐词出现，间隔 25ms、时长 1.2 秒，保持大写及当前字重。
- 滚动只触发一次；组件卸载取消动画并断开观察器。

验证：生产构建成功；加载、首屏先后顺序、About、角色区域和手机减少动态模式共 10 项 Playwright 检查通过。
