# 文字浮现与首屏入场节奏

参考来源：本地 Meer-Mohsin-Replica/src/app.js、scroll.js、layout.css；原站 https://www.meermohsin.me/ 。

- 背景大字从下方上移，时长 2 秒；人物延后 0.5 秒开始，3.5 秒完成上移、0.9 到 1 的缩放及亮度恢复。人物保持不透明，避免背景文字透出。
- 加载期间暂停首屏动效，加载结束后开始；减少动态效果模式直接显示完整画面。
- About 标题逐字、正文逐词随机错峰浮现：上移 40px、4px 模糊到清晰，间隔 50ms；标题单字 1.2 秒、正文单词 3 秒。艺术体 FEEL 作为一个整体保留字形。
- 三个人格标题逐字、英文描述逐词出现，间隔 25ms、时长 1.2 秒，保持大写及当前字重。
- 滚动只触发一次；组件卸载取消动画并断开观察器。

验证：生产构建成功；加载、首屏先后顺序、About、角色区域和手机减少动态模式共 10 项 Playwright 检查通过。

## 用户复核后的首屏修订

此前人物 brightness(0) 带来黑影感，且动效作用在裁切容器而非文字上。本次取消人物亮度动画，改为真实签名完成事件驱动入场。

1. 数字加载结束后，粉色背景上先书写签名，人物及背景大字隐藏。
2. 签名完成后停留 650ms，随后签名移向左下角，同时背景大字从固定裁切窗口下方向上进入，时长 2 秒。
3. 人物再延后 600ms，以正常色彩上移、轻微放大并展开，时长 2.4 秒；不使用黑色提亮或整体透明度渐变。
4. 通过 SVG alpha 轻微羽化保留实心中心，衣服底部用渐变蒙版融入背景，保持五官清晰。
5. 减少动态效果模式直接展示最终构图。

本次验证：生产构建及 8 项首屏检查通过，包括先签字、文字在裁切窗口内移动、人物无 brightness 动画、手机端和鼠标特效。

### 人物淡入修订

按用户复核，人物改为原位透明度 0→1 淡入（2.4 秒，延后背景字 600ms），取消入场的 translate、scale 和 clip-path。保留正常色彩与边缘柔化。鼠标视差仍只影响外层容器。验证采样确认人物入场前后位置及宽度保持不变，中途透明度位于 0 和 1 之间，最终完全不透明；生产构建及两项针对性检查通过。
