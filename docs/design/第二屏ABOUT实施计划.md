# 第二屏 ABOUT 实施计划

用户已确认保留参考站正文，并授权开始实施。仅接入 `/stage` 第二屏。

1. 新增浏览器用例：滚动进入 ABOUT、原文准确、加载不重播、减少动态和手机无溢出。
2. StageAbout 独立组件：三行标题 THIS WILL / FEEL / DIFFERENT，Ruthie连笔中行，正文逐词呈现；可读静态内容为默认，动画为增强。
3. 新增局部样式：暖黑背景、柔粉标题，桌面约135vh的布局；手机保留构图但取消危险的负偏移。
4. 插入 StageHero 后，保留原首屏、计数与粉色流体。滚入第二屏时仅调整页头对比度。
5. 构建、浏览器截图与首屏回归后提交。

不实现原站下一段数字区、能力区，也不引入他人的翼形模型。正文精确使用用户选定英文，不自动替换或翻译。
