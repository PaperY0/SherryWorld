# 首屏黑粉与流体修订

2026-10-17，范围 `/stage`，用户要求：更明显粉色渐变、底部偏黑、人物不透字、签名更大更快且修复书写、粉色鼠标与参考站流体。

## 诊断

- 透明人物 PNG 主体抽样 alpha=253/255，并叠加入场 opacity0→1。移除人物淡入，仅保留位移，SVG alpha transfer slope1.04 将主体变为不透明，仍保留外部透明背景及边缘。未重绘或重生成人物。
- 签名原遮罩宽28，栅格覆盖核对有287/34515个核心墨迹像素未覆盖（约0.83%）。遮罩宽40时全部34515个核心墨迹像素覆盖。核心定义为原PNG alpha>100，遮罩 alpha>=200。此检查证明完整时覆盖，不能替代运动中交叉笔画的视觉确认。
- 签名不换字形、不换颜色；显示 viewBox 裁去透明边距以放大有效字形。书写时长由4.3秒缩至3.22秒，起笔等待由0.9秒改0.6秒。

## 实现

- 多层粉色径向与斜向渐变，底部叠加暖黑；底部小字换浅色。
- 签名大屏有效字号与完成后的角落字形均放大。
- 粉色原生 SVG 箭头，作用于该预览页面及页头；手机使用系统交互，不强行显示鼠标。
- 沿用参考站使用的 webgl-fluid 0.4.0，保留主要模拟参数，将 splat RGB 改为粉色。
- 上游库没有显式公开销毁 API，使用独立同源 iframe 持有库的GL、RAF和监听器；卸载 iframe 时由浏览器销毁整个运行上下文。iframe pointer-events:none，父页面仅传鼠标坐标，不拦截按钮。消息检查 origin 和 source。
- 减少动态或粗指针设备不创建流体层；WebGL初始化失败时保持页面按钮可用。
