# PaperY 人物小样资产规格

日期：2026-10-04。执行已确认的第一轮计划任务 4，附独立试验页 `/avatar-lab`。

造型遵循 V5：黑色长发与自然刘海、黑框大眼镜、画面右侧耳旁银白内层发束，暖肤色、闭口微挑嘴角。比例采用 Q 版收藏公仔的上半身，不追求写实皮肤。Light 黑针织，Dark 珍珠灰衣服；环境沿用暖白、暖炭灰与柔粉。

初始检查没有检测到 Blender，因此先生成程序几何 V1，作为体积、发束位置与转动试验。用户追加要求后已安装 Blender 4.5.14 LTS 和 MCP，并调整为先生成三视图再在 Blender 中建模；最新进度见 `../plans/人物小样与Blender环境进度.md`。图片生成只能给视觉参考；程序小样不等于最终人物完成，也不以 PNG 贴片冒充三维几何。

模型以 +Z 为正面，Y 为竖直方向。按完整头顶与肩部范围设置正交相机；所有尺寸均按模型实际包围盒适配。分离皮肤、头发、银白发束、眼镜与衣服材质。控制节点使用实际模型中存在的根节点与头部节点；这一阶段先验证轻微呼吸、有限转头与两侧造型，不声明有骨骼蒙皮或完整表情绑定。

工程仅在独立试验页加载 Three.js 与 GLB；首页保留已确认 V5 稿，待造型比较通过后再替换。加载失败或无 WebGL 显示静态参考，保留导航。离屏与后台停止渲染；减少动态默认暂停，手动方向键和视角按钮仍可操作。主题只改变灯光与衣服材质，不重新加载模型。

## 验收重点

- 正面、左右约 35 度视角具有实际厚度，眼镜与鼻子不会漂浮穿模。
- 银白内层发束从耳侧垂向肩前，与黑色外层区分。
- 不把明显皱眉或愤怒当作略拽；脸型、五官比例与人物参考需要人工比较。
- 1440×900、390×844 与短屏能看到完整头顶，无横向溢出。
- 实际 GLB 可下载，可用源脚本重复导出；资产清单记录字节、几何、材质、能力及未完成项。
- 自动化检查覆盖模型加载、旋转、主题换衣、暂停、减少动态与失败替代；截图作为造型证据，不代表用户已认可相似度。

技术参考：[Three.js 官方文档](https://threejs.org/docs/)；依赖版本锁定到工程文件。
