# PaperY · 环形项目画廊交互设计

版本 V1.1 · 2026-10-03。依据用户提供的横向弧形图片带参考，替代先前“镜头沿美术馆展墙前进”的设想。

## 确定的形式

作品封面横向排列在一条浅弧形轨道上，中央封面较正，左右封面有轻微透视角度。桌面一屏主要展示 4–5 张大封面，两侧增宽、增高，使上沿向上、下沿向下展开。画面保留暖白或深灰背景、大面积留白、黑白文字与低饱和柔粉点缀。没有展厅墙面、金属框或长走廊。

标题固定为单行全大写 BUILT IN MY OWN WAY.，保留上方 PAPERY · SELECTED WORKS；删除原先标题下的两行中文，不在后续正式版中恢复。

进入项目区时，封面从上方分次出现，柔和落到弧形位置。正文标题与导航保持稳定，封面运动不推动页面布局。

## 行为表

| 情况 | 画廊行为 |
| --- | --- |
| 鼠标不移动 | 默认从右向左缓慢连续循环 |
| 鼠标向左移动 | 从右向左流动，速度随移动幅度适度增加 |
| 鼠标向右移动 | 从左向右流动，平滑减速后反向 |
| 停止移动约 1.1 秒 | 平滑恢复默认右向左循环 |
| 按住拖动 | 封面跟随左右拖动，停止自动推进 |
| 结束拖动 | 恢复缓慢右向左循环 |
| 点击封面 | 暂停画廊并打开项目介绍面板 |
| 关闭介绍 | 恢复参观位置与循环 |
| 键盘聚焦作品 | 暂停运动，回车可打开介绍；左右键可移动 |
| 点击暂停 | 停止循环，保留手动参观入口 |
| 页面不可见 | 暂停自动推进 |
| 系统减少动态 | 默认暂停并省略上方入场，可主动选择播放 |

方向以鼠标移动的水平增量判断，不以屏幕左右区域判断。设置小幅噪声阈值避免方向抖动，速度插值避免瞬间急转。纵向滚轮保留正常网页滚动；它把访客带入或带出画廊，不被强制转换为横向滚动。

循环采用模运算位置映射；作品在可视区外绕回另一端，无需堆叠越来越多的节点。全部作品来自同一份内容索引，点击克隆或循环位置时都指向原项目。

## 项目内容与入口

画廊分为 12 个非 Fork 作品和 4 个学习 / Fork 仓库，均有明确入口；作品先展示知野、Lumi、zxcvbn-MoonBit。目录模式能快速定位所有 16 个仓库。

封面点击打开介绍，包含名称、项目说明、技术或类型、本人职责、当前状态和 GitHub 按钮。GitHub 在用户点击后打开新标签；不在用户拖动时意外跳转。

用户已说明所讨论的项目由本人全栈负责、采用 Vibe coding 工作方式。网站使用“全栈负责 · AI 辅助开发”的表达；具体产品定义、技术选择、整合、调试与验证记录逐步补齐。全栈负责是用户自述，不能被写成全部代码纯手工编写或成果已独立测试。Fork 仓库保持来源标识。

正式封面优先使用项目真实界面、截图、录屏关键帧或经过确认的项目海报。当前预览采用有文字标识的概念海报，不冒充真实运行界面。

## 双主题与手机

Light 为暖白背景与近黑文字，Dark 为暖调深灰黑与白色文字；概念海报各自保留设计色，未来真实截图也不简单整体反色。柔粉作为细节贯穿两个主题。

手机每次展示一件主体作品和两侧部分邻作。触屏横向拖动参观，纵向滑动仍能离开画廊；没有鼠标时不模拟鼠标方向事件。暂停、上一件、下一件和目录一直可用。

## 原型范围

[打开交互原型](../../prototypes/项目画廊交互原型.html)。可以离线直接用浏览器打开，不需要安装依赖或运行服务。

预览使用 CSS 3D 变换展示曲面轨道上的封面平面，验证方向、循环、入场、主题和点击行为；它不包含真实项目截图，也不是完整个人网站或个人角色 GLB 模型。正式站可以继续使用 CSS 3D，或根据实际效果与性能需要改为 Three.js 平面。是否采用 WebGL 不改变项目数据和介绍内容。

## 后续验收

- 经过完整一圈，作品顺序和首尾连接一致，不出现空白或闪跳。
- 向左、向右移动鼠标与默认静息方向符合行为表。
- 拖动后不会误点打开项目；介绍开启时不继续自动流动。
- Light / Dark 不改变当前位置和项目身份。
- 12 件作品与 4 个 Fork 都可从目录进入，并对应准确 GitHub URL。
- 手机能横向参观和纵向滚动；减少动态下默认暂停。
- 最终换用真实封面后，页面仍保持留白，封面文字清楚可读。
