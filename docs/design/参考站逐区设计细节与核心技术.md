# 参考站逐区设计细节与核心技术

2026-10-17。本轮实现范围只有 `/stage` 人物首屏预览。本文供逐块评审，后续区域不按上一版建议自动重做。

## 1. 怎样做到少改

采用“骨架与动作保留，身份内容替换”的方式：每个区域先确认构图、进入方式、滚动时间、退出方式，再改人物/配色/字句。原来的奖项、作品和职业介绍必须替换成真实内容，其余布局无需因此推翻。

完整逐项原文、原长段落、项目和文章正文见《参考站全部文字与字段.md》。此文件解释每一块怎么设计、哪些只需换字、哪些涉及动作和结构变化。

## 2. 全站视觉规则

- 黑红基调，红色既在背景渐变，也在模型灯光、流体、加载着色器、菜单色带、强调按钮出现。改黑粉不能只改一个 CSS 变量，灯光、shader、流体配置也要检查。
- 大幅字号与很小的边角文字形成反差；多数段落依靠位置和留白组织，而非卡片边框。
- 人物、巨字、模型、光标、导航、弹窗分别处于不同图层；误改 z-index 会让可点击内容被遮挡。
- 全站采用视口比例尺寸，主 CSS 的 html font-size 是 .8333vw；因此 rem 和常见 16px 基准不同。迁入当前站时应限定在容器，不能全局照搬。
- 原字体为 StackSansHeadline 的轻/常规字重与 Ruthie 连笔体；当前小样使用现站系统字体，签名用本人 PNG，没有复制原站文字商标。
- 参考站断点有 700/768/800px，不是统一一个手机断点；触摸交互和鼠标交互分别处理。

## 3. 加载屏

**画面**：整屏红色噪声，中心三位数字；提示 CLICK ANYWHERE TO ACTIVATE THE EXPERIENCE。

**动作**：导航时判断 sessionStorage 与 reload；首次播放计时数值 000→100，约 2.9 秒后触发约 3 秒的噪声溶解；其后人物、文字入场。首屏文字原设有约 8.5 秒延迟。

**技术**：正交相机＋全屏平面＋ShaderMaterial。uniform phase 控制溶解进度，time 让噪声边界和亮边变化；renderer RAF 持续绘制。加载数字不测量网络下载。

**最小修改**：把 shader 中红色 RGB 改粉色，数字/字体保留；提示双语。也可以只缩短等待，不改变溶解结构。现阶段未移植，不叠加到当前欢迎视频。

## 4. 人物首页

**画面层级**：渐变背景 → 横向巨字 → 满屏居中肖像 → 前景模型 → 小字/导航 → 左下音频和右下联系 → 自定义光标。人物并非实时三维人脸。

**原文字**：

- 循环巨字：It Was Always Going to Be This Way.（重复是循环需要）。
- 左侧：I create digital experiences that aren't just seen they're felt. From the first impression to the smallest interaction, I focus on making every experience clear, immersive, and memorable.
- 右侧：VISUAL STORYTELLER / UI/UX DESIGNER / 3D WEB DEVELOPER。
- 底栏：TENSION / IMMERSION / IMPACT，穿插加号。

**动作**：肖像由暗到亮、由轻微位移和缩小回位；巨字入场后持续横移。滚轮方向决定巨字速度正负，短暂加速再减速；底部十字随页面滚动旋转。

**当前小样修改**：人物换为 Sherry 透明素材；黑粉双主题；巨字 A WORLD OF MY OWN.；身份 AI · BACKEND · AGENT；底栏 BUILD / FEEL / EXPLORE；原图签名逐笔揭示后缩到左下。除此之外的文案和尺寸均可继续局部微调。未复制原站全套导航收起、3D 装饰、音乐和流体。

**人物素材边界**：透明素材由已有封面使用内置生图工具提取，保留黑框眼镜、挂耳银白染和灰色针织上衣；它是生成式处理后的素材，可能有发丝边缘差异，需要用户确认。没有新建人物 3D 模型。

## 5. 翼形装饰与签名

**原结构**：加载 model1 GLB，经 Box3 计算中心和最大边归一化，再 clone 成两个模型，配不同粗糙度、金属度。主光红色跟随鼠标，环境光与点光叠加。位置、旋转和相机由入场及滚动时间线控制，因此会出现落到人像前的效果。它不是给肖像图片加滤镜。

**签名结构**：PNG 保留真实颜色和笔形；六段中心路径作为 SVG mask，用浏览器 Web Animations API 顺序改变 strokeDashoffset。写完解除遮罩，显示原始 PNG；再用 CSS 位移缩小到角落。原图本身没有笔顺，当前是人工设计的书写顺序，而非记录用户真实落笔。

**取舍**：当前签名是二维前景层，能逐笔书写；没有声称它拥有原 GLB 的立体厚度或 3D 自转。后续如果保留“从上落下”，只需要在签名外层编排位移/透视，不必改签名笔形。

## 6. 导航与移动菜单

**桌面**：顶部两列小字。一列 HOME / ABOUT / SERVICES / WORK / BLOG / CONTACT US；另一列社交。锚点点击交给 Lenis，不一定写入 URL hash。下滚字符收起，约 3 秒后恢复。

**手机**：两根横线按钮；点击后五条背景栏从右侧展开，逐条错开约 .06 秒，持续约 .8 秒；按钮旋转为 X，logo 变黑。菜单项点击关闭并平滑滚动。

**最小修改**：位置、色带和动作保留，换为粉色和本人导航名称；账号链接替换。不要为增加两个栏目重画整个菜单。

## 7. 关于我

**画面**：大标题 This Will / Feel / Different，Feel 使用连笔字体；配长段个人宣言，不是头像资料卡。

**动作**：SplitType 把字符/词拆到可动画元素，GSAP 让它们从 y 偏移、透明和 blur 到完整出现；部分顺序随机，滚动到触发位置后执行。

**原正文**：I don't just build websites I create experiences that people enjoy exploring. From the first impression to the smallest interaction, I care about the details that make a website feel smooth, memorable, and worth coming back to.

**最小修改**：保留三行大标题和连笔字位置，只改标题与本人介绍。想保留 Feel 也可以。中文应按词/句设计，不能直接沿用英文空格拆词。

## 8. 三个数字

**画面**：10+ / 25+ / 6+，两侧火焰 GIF，数字旁有三段说明。

**全部说明**：Each one different. Each one demanding something sharper. / Each one pushed beyond the obvious. / Learning fast. Moving faster.

**动作**：数字字符和说明依次上移显现；并非有明确单位的真实统计计数器。

**最小修改**：数字区结构和火焰位置可保留，统计内容换成有证据且有单位的个人信息，或改成三个身份词。火焰是否保留由审美选择，不自动删。

## 9. 能力长滚动舞台

**入场**：LEGACY 的字符逐个放大并向上退出，场景从简介转到能力。

**主舞台**：约 690% 视口的固定区间；UI - UX 和 3D WEB 依次出现，附 expertise 清单。图片通过 clip-path 揭示，图内内容从 yPercent 40 到 -40 产生深度。桌面浮动图片受鼠标位置驱动产生 rotationX/Y。

**原全部标签**：UIUX / 3D Web development / Problem Solver / User Research / Frontend Engineering / Three.js / WebGL / GSAP Animation / Performance Optimization。

**衔接段原文**：Design attracts attention. Development brings it to life. I combine both to create websites that not only look exceptional but also feel fast, intuitive, and memorable.

**最小修改**：保留两段切换时间线，只把 UI - UX / 3D WEB 改成用户选定的两个主题，例如 AI AGENT / BACKEND，再换配图和标签。增加第三主题才需要重新分配时间线，不应未经确认自动增加。

## 10. 下落与撕纸

**画面**：下落 GIF 独立层进入，再扩展为全屏；撕纸边缘图从缩放状态展开，文字露出。

**原文**：The fall was always / part / of the path. / And from that point, everything began to rebuild with intention.

**最小修改**：可以仅改粉色与文字，保留下落和撕纸视觉；不需要因为个人没有相应故事就删除整段。正文可写创作过程，而非虚构个人遭遇。

## 11. 作品滚动与侧栏

**构图**：作品图居中，当前卡 top25% scale1；上一卡 top-10% scale.3，下一卡 top60% scale.3；旁边展示标题、说明和圆形进度编号。

**数据**：CODENARTS / AZ DIGITAL VENTURES / AMRON / CHATONE / FINANCE。每项的摘要、日期、角色、技术标签和全部描述已完整提取到原文清单，不在本文件省略替换为假文案。

**滚动算法**：将 progress 映射到 0–4 的索引，再按 relative=index-current 选择卡片状态。切换时更新背景、标题、摘要、圆环和点击目标。duration/scrub 决定平滑感，不能只调整 CSS top。

**打开详情**：面板自下用 clip-path 展开约1.7秒；底层淡到 .3，禁止点击和滚动；面板内可滚。内容为大图、日期、描述、标签、Gallery 图库、Contribution 列表。关闭做反向裁切并恢复滚动。

**最小修改**：如果这次决定少改参考站，先保留纵向切换，只换真实作品图和数据；之前横向画廊作为另一个现有版本保留。两种排布要让用户对照再选，不自动更换。项目数量不限定5，需要从数组长度推导进度与固定区间。

## 12. 四步过程

**画面**：Discovery / Creative Direction / Digital Craftsmanship / Launch & Evolution 四段文字，配工作过程图片和总说明。

**动作**：每块从 y120 和透明入场，标题词语再错峰出现；图像沿滚动 yPercent-20、缩放变化。滚回可反向，不是所有揭示都是 once。

**总标题**：From the First Idea to the Final Frame Every Step Is Crafted to Create an Unforgettable / Digital Experience.

**最小修改**：可以只将四个标题改为实际开发四步，段落写本人经历；图片排布和时序保留。所有原段落已逐字保存到原文清单，修改时逐段对照，不整段自动重写。

## 13. 日记三卡与文章

**画面**：VISUAL JOURNAL，两列大小标题和介绍；三张图片卡错落，中间卡随滚动上移。

**卡面原文**：Motion Beyond Animation（July 1, 2026）；The Psychology of Dark Interfaces（June 14, 2026）；Designing Experiences, Not Websites（May 22, 2026）。

**弹窗原文**：Designing Through Motion（June 12, 2026）；The Power of Cinematic Interfaces（May 28, 2026）；Crafting Emotion With Color（April 18, 2026）。三者作者均 MEER MOHSIN，正文已存原文表。卡片和详情有不一致。

**动作**：文章从中心裁切框打开，rotation -10→0、scale .7→1，约1.6秒；图片另做裁切。弹窗打开停止平滑滚动，Escape/背景/关闭按钮可退出，busy 标记防重入。

**最小修改**：只替换照片、标题和正文即可承载兴趣/生活/故事，布局不用改。卡面和详情统一数据源。也可以保留技术文章用途，兴趣另放下方，不自动决定。

## 14. 奖项展台

**画面**：AWARDS & RECOGNIZATIONS，左右分屏遮罩打开，三张奖项图在三维展台上，随后屏幕合拢。

**原正文**：Forged in obsession, shaped in darkness, and recognized beyond the screen. These awards mark the moments when the work became impossible to ignore.（出现两次。）

**技术**：独立 WebGLRenderer、PerspectiveCamera、GLTFLoader＋MeshoptDecoder、ACES 色调映射；三张纹理分别贴 PlaneGeometry，camera position/rotation 随约4.5屏固定滚动时间线改变。

**最小修改**：展台、三张图片平面和镜头保留，只换成旅行照片及标题即可成为旅行展示；若有本人奖项也可继续使用奖项主题。无需重建整个 3D 场景。当前尚未把旅行照片接进展台验证。

## 15. 联系与页脚

**大字**：Every Great Story Needs A Powerful / Ending.；LET'S BE / CREATIVE。

**布局**：大标题、环状图形 CTA 与底部循环语；原模型进入页脚并自转，伴随单独页脚声音资源。

**联系面板**：GET IN / TOUCH，四个必填项 Your Good Name / Your Number / Your Email / Please type your concern here!，按钮 Submit。入口从下面整屏展开，关闭向上收起。

**悬浮 CTA**：ONLINE / Let's Connect，头像；默认跳原作者 WhatsApp。下滚隐藏，上滚恢复，鼠标接近有磁吸。

**最小修改**：文字和联系人替换，动作保留；手机号可以删除必填。第一版邮箱/GitHub 直接可用。真实表单需个人服务配置，不能把默认模拟成功呈现为邮件已送达。

## 16. 核心技术对照：理解到什么程度

|技术|参考站具体用途|本轮理解与复用|尚需专项验证|
|---|---|---|---|
|GSAP Timeline|将图片、词语、背景、模型动作编排到统一时轴|已阅读时间线顺序及参数；当前一屏用 CSS/WAAPI 实现所需时序|完整重建参考站所有中间帧|
|ScrollTrigger|pin固定舞台、scrub绑定滚动、阶段回调|已梳理区间、pin对象和回调；本轮未复制长页pin|多区pin叠加、窗口resize、真实手机反向滚动|
|Lenis|统一平滑滚动与滚动暂停|已读 ticker 接入和弹窗 stop/start；本轮未引入|固定欢迎页门槛与长页平滑滚动整合|
|SplitType|将英文文字拆字符/词/行|已确认标题/段落拆分与 stagger|中文断行、字体加载后重拆分、读屏语义|
|Three.js|前景双模型、鼠标灯光、奖项展台|已核对相机/灯/归一化/贴图/时间线绑定|粉色灯光、GPU回退、真实素材切换后的画面|
|GLTF/Meshopt|加载压缩模型资产|已梳理 loader 与模型节点|模型授权/替换/材质重调和内存释放|
|WebGL shader|加载屏噪声溶解、边缘亮光|已读 phase/time uniform 和数学作用|粉色版本跨GPU一致性|
|webgl-fluid|鼠标粉尘/液体拖尾|已读红色 splat、分辨率、耗散参数和触摸转发|粉色调参与移动性能|
|RAF循环|跑马灯和灯光持续更新|本轮已实现按时间delta横移、滚轮方向加速、鼠标轻微视差和清理|持续性能实测而非凭源码猜测|
|SVG mask + WAAPI|参考站无个人签名书写；本轮新增|原图＋分笔路线与重播；支持减少动态|笔画交叉处与个人审美确认|
|clip-path|项目/文章/联系展开与图片揭示|已定位每类入场/退场/锁滚边界|迁入React后的焦点陷阱、Escape统一关闭|

“学会核心技术”在本项目的可核实含义：能说明每个画面的输入、动画状态、触发、退出和依赖，能在自己的站点实现并测试。此表不会把未运行的参考功能标为已验证，也不把使用库等同于能重写底层渲染引擎。

## 17. 后续逐块审阅方式

每次只选一个区域，给出：参考截图 → 原文全文 → 仅修改的字句/图片 → 保留的动作 → 实际小样。用户未选择的区域不自动改版。所有链接、身份、项目与奖项在正式上线前都必须是 Sherry 的真实内容。
